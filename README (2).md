# Асинхронность в Python — Домашнее задание (Модуль 3, Урок 4)

Репозиторий с выполненными теоретическим и практическими заданиями по теме **«Асинхронное программирование в Python»** (сквозной сюжет — асинхронный загрузчик URL на `httpx` и `asyncio`).

---

## Структура репозитория

Каждое задание вынесено в отдельный самодостаточный файл с подробным `docstring` в начале (содержащим замеры времени и объяснения согласно рубрикатору), а теоретическая часть оформлена в `theory.md`:

```text
.
├── README.md          # Описание проекта, инструкция по запуску и сводная таблица замеров
├── theory.md          # Конспект теории из лекции и разбор архитектурных вопросов в формате Markdown
├── requirements.txt   # Зависимости проекта (requests, httpx)
├── .gitignore         # Исключения для Git (.venv, __pycache__ и др.)
├── task_0.py          # Задание 0: Разминка-ловушка «Почему не быстрее?»
├── task_1.py          # Задание 1: Синхронно vs асинхронно
├── task_2.py          # Задание 2: Реальный I/O и обработка ошибок (таймаут, backoff, изоляция падений)
└── task_3.py          # Задание 3 (*): Вынос CPU-bound-вычислений в ProcessPoolExecutor
```

---

## Быстрый старт и проверка работы

### 1. Создание и активация виртуального окружения

**Linux / macOS:**
```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows (PowerShell / CMD):**
```powershell
python -m venv .venv
.venv\Scripts\activate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Запуск заданий

Каждое задание запускается отдельной командой:

```bash
python3 task_0.py
python3 task_1.py
python3 task_2.py
python3 task_3.py
```

## Самопроверка по рубрикатору

1. **Оформление и структура сдачи:** каждое задание в отдельном файле (`task_0.py` – `task_3.py`), в начале каждого файла оформлен `docstring` с объяснениями и реальными замерами времени, рядом лежит `theory.md`.
2. **Задание 0:** объяснена причина медлительности последовательного `await` в цикле `for`, код исправлен через `asyncio.gather` (и показан вариант с `asyncio.TaskGroup`), указан флаг `follow_redirects=True`, приведены замеры времени.
3. **Задание 1:** реализованы `sync_main` на `requests` и `fast_main` на `httpx.AsyncClient` + `asyncio.gather`, выполнены замеры времени и дано лаконичное объяснение разницы.
4. **Задание 2:** в `robust_fetch` добавлен таймаут на запрос и ретраи с экспоненциальным ростом паузы (`1 с -> 2 с -> 4 с`, 3 попытки); `robust_main` использует `return_exceptions=True` и возвращает кортеж `(results, errors)`, не падая на битых URL (`no-such-site.invalid`, `httpbin.org/delay/10`).
5. **Задание 3 (\*):** реализована функция `heavy` (`sha256`), наглядно показано замирание `ticker` при прямом вызове в корутине и непрерывный вывод точек `ticker` при выносе вычислений через `loop.run_in_executor` + `ProcessPoolExecutor`.
